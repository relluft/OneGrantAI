## OBS Studio Setup Guide

### Step 1: Download & Install
1. Go to **https://obsproject.com** → Download OBS Studio (free, open source)
2. Install with default settings
3. Launch OBS Studio

### Step 2: Configure Scene
1. Click **"+"** under **Sources** → Add **"Display Capture"** (captures your entire screen)
2. Select your monitor → OK
3. **Resolution**: Go to Settings → Video → Set **Base Resolution** to `1920x1080` and **Output Resolution** to `1920x1080`
4. **FPS**: Set to `60` for smooth recording
5. **Recording Format**: Settings → Output → Recording → Set format to **mp4** or **mkv**
6. **Recording Quality**: Set to **"High Quality, Medium File Size"** or **"Indistinguishable Quality"**

### Step 3: Prepare Browser
1. Open Chrome/Edge in **maximized** mode (not F11 fullscreen — you need the tab bar hidden but window controls visible)
2. **Hide bookmarks bar**: Ctrl+Shift+B
3. **Close all extra tabs** — only `localhost:5173` open
4. **Set browser zoom to 100%**: Ctrl+0
5. **Optional**: Use a browser extension to hide the address bar for a cleaner look (e.g., "Fullscreen Window" extension)

### Step 4: Record
1. Press **"Start Recording"** in OBS
2. Run the Playwright demo script (I will create it — just run `npx playwright test demo_recording.ts`)
3. When the script finishes, click **"Stop Recording"** in OBS
4. Your video file is saved in OBS's default output folder (Settings → Output → Recording Path)

### Step 5: Add Voiceover
1. Download **CapCut** (free, https://www.capcut.com) — best for beginners
2. Import the OBS recording
3. Record your voiceover reading the script above — you can do it directly in CapCut
4. Trim, sync, and add any text overlays you want
5. Export at 1080p 60fps
