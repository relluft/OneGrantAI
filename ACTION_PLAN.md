## 📋 YOUR TODO LIST (in order)

### Step 1: Install OBS Studio (10 min)
1. Go to https://obsproject.com → Download → Install
2. Open OBS → Settings → Video → Set `1920x1080`, `60 FPS`
3. Settings → Output → Set Recording Format to `mp4`, Quality to "High Quality"
4. Add Source → "Display Capture" → select your monitor

### Step 2: Install CapCut (5 min)
1. Go to https://www.capcut.com → Download desktop version → Install
2. This is where you'll combine video + voiceover

### Step 3: Prepare the App for Recording (5 min)
1. Open Terminal 1: `cd backend && python main.py`
2. Open Terminal 2: `cd frontend && npm run dev`
3. Make sure your `.env` has the OpenRouter API key (for live AI generation)
4. Open `http://localhost:5173` in Chrome/Edge
5. Have OneWallet extension ready with testnet tokens
6. Hide bookmarks bar (Ctrl+Shift+B), close extra tabs
7. Turn on Windows Focus Assist (Settings → System → Focus Assist → "Alarms only")

### Step 4: Ask Me to Create the Playwright Script (5 min)
1. Tell me: "create the Playwright script"
2. I will generate `demo_recording.ts` with smooth automated mouse movements
3. You'll run it with: `npx playwright test demo_recording.ts`

### Step 5: Record the Video (15 min)
1. Click "Start Recording" in OBS
2. Run the Playwright script OR manually navigate through the app following VIDEO_PLAN.md
3. Go through all 7 scenes in order
4. Click "Stop Recording" when done
5. **Tip**: Do 2-3 takes. Pick the best one.

### Step 6: Record Voiceover (15 min)
1. Open CapCut → Import the video recording
2. Read the English voiceover script from `VIDEO_PLAN.md`
3. Record directly in CapCut (built-in mic recording) or use your phone and import the audio
4. **Speaking time**: ~2:20 of narration over ~2:50 of video
5. **Tips**: Speak naturally, pause at transitions, emphasize the "meta moment"

### Step 7: Edit & Export (15 min)
1. Sync voiceover with video in CapCut
2. Add text overlay at the end: "Built by a solo degen builder. For OneChain. With ❤️"
3. Optional: Add zoom effects on key button clicks
4. Export at 1080p, 60fps
5. Keep total under 3 minutes!

### Step 8: Submit (10 min)
1. Upload video to YouTube (unlisted) or Google Drive
2. Prepare your submission with:
   - Project name: **OneGrant.AI**
   - Video link
   - GitHub repo link
   - `SUBMISSION.md` content (copy/paste relevant sections into the submission form)
3. Submit before the deadline!
