# OneGrant.AI

> **AI-Powered Grant Discovery & On-Chain Application Platform for OneChain**

OneGrant.AI is a comprehensive platform that revolutionizes how Web3 builders discover, apply for, and track grants and hackathons. It combines AI-driven idea generation, intelligent matching, and on-chain Proof-of-Idea recording.

## 🚀 Quick Start

### 1. Prerequisites
- Node.js (v18+)
- Python (v3.10+)
- OneWallet Browser Extension

### 2. Installation

**Backend:**
```bash
cd backend
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env      # Add your OpenRouter API key
python main.py
```

**Frontend:**
```bash
cd frontend
npm install
cp .env.example .env      # Add VITE_API_URL=http://localhost:8000
npm run dev
```
